# 会議弁当経費処理用議事録管理システム 要件定義書

## 1. システム概要

会議時に支給する弁当の経費処理に必要な議事録を、効率的かつ確実に作成・管理するためのWebアプリケーション。
領収書画像から日時を自動抽出し、事前定義された議題から選択することで、最小限の入力で税務要件を満たす議事録をGoogleスプレッドシートに記録する。

## 2. 背景・目的

### 2.1 背景
- 会社では会議時に弁当を支給しており、これを経費として処理している
- 税務上、経費として認められるには会議の実施記録（議事録）が必要
- 現状の議事録作成には手間がかかり、抜け漏れのリスクがある

### 2.2 目的
- **税務処理の簡略化**: 必要最低限の情報で税務要件を満たす
- **入力の最小化**: テンプレート化と自動抽出により人的作業を削減
- **抜け漏れ防止**: システム化により必要事項を確実に記録
- **認知負荷の軽減**: 定型的な作業を自動化し、判断を要する部分のみ人間が関与

## 3. ユーザー・利用シーン

### 3.1 対象ユーザー
- **主要ユーザー**: 経理担当者
- **副次ユーザー**: システム管理者（MITSURU氏）

### 3.2 利用シーン
1. 会議実施後、弁当の領収書を受領
2. 領収書をスキャナーでスキャンして画像化
3. システムに画像をアップロード
4. 自動抽出された日時を確認（必要に応じて修正）
5. 該当する議題を選択
6. 議事録作成ボタンを押してスプレッドシートに記録

## 4. 機能要件

### 4.1 画面構成

システムは以下の3つの主要画面で構成される：

1. **ログイン画面**
2. **議事録作成画面**（メイン画面）
3. **設定画面**

### 4.2 各画面の機能詳細

#### 4.2.1 ログイン画面

**機能**
- Googleアカウント認証によるログイン

**要件**
- 認証成功後、議事録作成画面に遷移
- 認証失敗時はエラーメッセージを表示
- セッション管理により、再ログインの手間を軽減

---

#### 4.2.2 議事録作成画面

**機能**
- 領収書画像のアップロード
- 日時の自動抽出と確認・修正
- 議題の選択
- 議事録のスプレッドシートへの記録

**画面要素**

1. **領収書画像アップロードエリア**
   - ドラッグ&ドロップまたはファイル選択で画像をアップロード
   - 対応形式: JPEG, PNG, PDF
   - アップロード後、画像のプレビューを表示

2. **日時入力・確認エリア**
   - OpenAI APIによる自動抽出結果を表示
   - 抽出失敗または修正が必要な場合は手動入力可能
   - 入力形式: YYYY-MM-DD HH:MM

3. **議題選択エリア**
   - 設定画面で登録された議題のリストを表示
   - チェックボックスまたはドロップダウンで複数選択可能
   - 選択された議題数を表示

4. **議事録作成ボタン**
   - 必須項目（日時、議題）が入力されている場合のみ有効化
   - クリックでスプレッドシートに記録
   - 処理中はローディング表示
   - 成功時は完了メッセージ、失敗時はエラーメッセージを表示

**処理フロー**

```
[画像アップロード]
    ↓
[OpenAI APIで日時抽出]
    ↓
[日時表示・確認/修正]
    ↓
[議題選択（複数可）]
    ↓
[議事録作成ボタン押下]
    ↓
[スプレッドシートに記録]
    ↓
[完了メッセージ表示]
```

---

#### 4.2.3 設定画面

**機能**
- 議題マスタの管理（追加・編集・削除）
- スプレッドシートURL設定

**画面要素**

1. **スプレッドシート設定セクション**
   - 議題マスタスプレッドシートURL入力欄
   - 議事録出力先スプレッドシートURL入力欄
   - 保存ボタン
   - 接続テストボタン（URLの妥当性確認）

2. **議題マスタ管理セクション**
   - 議題一覧表示（テーブル形式）
   - 議題追加ボタン
   - 各議題に対する編集・削除ボタン
   - 議題追加/編集用モーダル
     - 議題名入力欄
     - 保存/キャンセルボタン

**データ同期**
- 設定変更は即座に議題マスタスプレッドシートに反映
- 議事録作成画面の議題リストも自動更新

---

### 4.3 データフロー

```
[領収書画像] 
    → [Vercel Functions] 
    → [OpenAI API (Vision/GPT)] 
    → [日時抽出結果]

[設定画面での議題管理] 
    → [Google Sheets API] 
    → [議題マスタスプレッドシート]

[議事録作成ボタン] 
    → [Vercel Functions] 
    → [Google Sheets API] 
    → [議事録スプレッドシート（追記）]
```

---

### 4.4 OCR（日時抽出）の詳細仕様

**使用技術**
- OpenAI Vision API または GPT-4 Vision

**処理内容**
1. アップロードされた領収書画像を解析
2. 日時情報を抽出（YYYY-MM-DD HH:MM形式）
3. 信頼度が低い場合や抽出失敗時はフラグを立てる

**エラーハンドリング**
- 抽出失敗時: 日時入力欄を空欄で表示し、手動入力を促す
- 抽出成功時: 自動入力し、編集可能な状態で表示

---

### 4.5 議事録の記録仕様

**記録先**
- Googleスプレッドシート（設定画面で指定されたURL）

**記録形式**
- 1議題につき1行
- 同じ日時に複数議題がある場合は複数行作成
- 最終行に追記

**記録項目**

| 列名 | 内容 | 備考 |
|------|------|------|
| 日時 | 会議（領収書）の日時 | YYYY-MM-DD HH:MM形式 |
| 議題 | 選択された議題名 | 議題マスタから取得 |
| 結論 | （将来拡張予定） | 現時点では空欄または固定文言 |

※ 結論欄の詳細仕様は実装中に検討

## 5. 非機能要件

### 5.1 認証・セキュリティ

**認証方式**
- Google OAuth 2.0による認証

**セキュリティ要件**
- アップロードされた画像は処理後に削除（一時保存のみ）
- スプレッドシートへのアクセスは認証されたユーザーのみ
- 設定情報の改ざん防止（ユーザーごとに設定を分離、または管理者のみ編集可能）

### 5.2 パフォーマンス

- 画像アップロード: 10MB以下
- OCR処理: 10秒以内
- スプレッドシート書き込み: 5秒以内
- 画面遷移: 1秒以内

### 5.3 可用性

- 稼働率: 99%以上（Vercelの標準SLA）
- メンテナンス: 計画的メンテナンス時以外は24時間利用可能

### 5.4 ユーザビリティ

- レスポンシブデザイン（PC、タブレット対応）
- 直感的なUI/UX
- エラーメッセージは具体的で分かりやすく

|------|------|------|
| ID | 議題ID | 自動採番または手動設定 |

### 7.2 議事録スプレッドシート

| 列名 | 内容 | 形式 |

| 日時 | 会議日時 | YYYY-MM-DD HH:MM |

※ 実装時に検討・決定

## 8. 制約事項・前提条件

### 8.1 制約事項

- 領収書画像は日時が明確に記載されているものに限る
- OCRの精度は100%ではないため、ユーザーによる確認が必要
- スプレッドシートへの同時書き込みは考慮しない（単一ユーザー想定）
- インターネット接続が必須

### 8.2 前提条件

- ユーザーはGoogleアカウントを持っている
- スプレッドシートへのアクセス権限が適切に設定されている
- 対応ブラウザ: Chrome, Edge, Safari（最新版）
